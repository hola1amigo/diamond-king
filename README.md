# ♦ 方片 K · Diamond King

五人数字心理博弈网页游戏，灵感来自《弥留之国的爱丽丝》。私密选数、限时决策、逐层追加规则，由服务器自动计分，无需裁判。

**1～5 名真人 · 策略机器人补位 · 手机浏览器可玩 · Node.js 22 · 代码 MIT**

本仓库提供自行部署的源码，不提供共享的公共游戏服务器。**一位组织者部署一次，朋友打开他的同一个网址即可一起玩**，不需要每位玩家租服务器。各部署的房间、积分和玩家身份互不相通，也不会连接到作者的服务器。

## 可以怎么玩

| 模式 | 适合场景 |
| --- | --- |
| 自动匹配 | 五名真人打开同一个网址，自动分房，全部准备后开始 |
| 好友房 | 使用房间码加入，房主选择 0～4 名机器人补满五席 |
| 单人挑战 | 一人对战四种策略机器人，正常计分与淘汰 |
| 流程演示 | 预设淘汰，快速查看结算、追加规则和结束播报 |

机器人根据本局公开历史和积分进行不同深度的预测，不读取本轮私密输入，不需要大模型 API。流程演示使用预设结果，与正式挑战不同。

## 本地快速开始

安装 [Node.js 22](https://nodejs.org/)，然后运行：

```sh
git clone https://github.com/hola1amigo/diamond-king.git
cd diamond-king
node "方片K/server.js"
```

在运行服务器的电脑打开 <http://localhost:3000>。当前版本没有第三方 npm 依赖，不需要安装数据库或填写 API key。

远程与朋友一起玩，请按 [自行部署指南](docs/DEPLOYMENT.md) 部署到自己的 Render 账号或 Node.js 服务器，并分享部署后的 HTTPS 首页网址。

## 规则概览

每人从 0 分开始，选择 0～100 的整数。目标值为已提交数字的平均数 × 0.8，最接近者获胜，其余玩家通常扣 1 分；累计至 −10 分淘汰。

人数减少后依次解锁重复数字失效、精确命中加罚及两人局特殊规则。连续两轮全员同数可提前解锁第一条规则。界面在解锁前隐藏追加规则，结算后逐条播报。

完整计分、超时、机器人和网络版改编说明见 [游戏说明](方片K/README.md)。这是非官方同人实现，包含适合网络游玩的改编，并非原作规则的逐字复现。

## 开发与限制

在仓库根目录运行检查：

```sh
node --test "方片K/server.test.js"
```

服务器使用 Node.js 内置 HTTP 模块，浏览器通过同源接口轮询状态。修改计分或房间逻辑时，请同时验证对应测试；界面变化还需要在手机浏览器检查。

- 房间仅保存在单进程内存中，重启、更新或平台回收实例会丢失对局。请在对局结束后更新。
- 同一浏览器可恢复座位；清除网站数据、换浏览器或换设备不能自动找回身份。
- 当前没有账号系统、持久化存档或多实例共享状态；适合小规模朋友对局，未进行大规模并发容量验证。
- 好友房使用房间码，没有额外密码。拥有站点地址的人仍可访问该站点；源码公开与站点访问控制是两回事。

欢迎通过 Issue 描述复现步骤、预期结果与实际结果，或提交范围明确的 Pull Request。请勿附带浏览器身份凭证、服务器密钥或私人对局信息。
